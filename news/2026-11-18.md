# ข่าวประจำวันที่ 2026-11-18

> หมายเหตุ: บอทรันเวลา 06:10 น. ตามเวลาไทย (ยังเป็นเย็นวันที่ 17 พ.ย. ตามเวลาสหรัฐฯ) จึงมีบทความที่ลงวันที่ 18 พ.ย. 2569 น้อย ด้านล่างนี้มีเฉพาะข่าวที่ประกาศหลังเที่ยงคืนวันที่ 18 พ.ย. ตามเวลาไทย หรือกำหนดการที่เกิดขึ้นวันนี้ ข่าวเก่า (14–17 พ.ย.) ตัดออกทั้งหมด

## 1. AI Model & Product Updates
- **Microsoft Ignite 2026 (keynote ตรงกับ 00:00 น. วันที่ 18 พ.ย. เวลาไทย)**: Satya Nadella ประกาศให้ Copilot เป็น "ระบบปฏิบัติการใหม่ของการทำงาน"
- **Copilot Workspaces**: พื้นที่ทำงานร่วมกันระหว่างคนกับ AI Agent ที่ใช้ context ชุดเดียวกัน เปิดให้ใช้ผ่านโปรแกรม Frontier ส่วน Personal Autopilot agent ยังอยู่ในสถานะ "coming soon"
- **Copilot Home** (รวม Chat + Cowork) เปิดใช้ทั่วไป (GA) แล้ว และ **Microsoft Copilot SDK ขึ้นเป็นเวอร์ชัน 2.0**
- **Agent ID / Defender**: Microsoft Defender จะสแกนการทำงานของ agent ใน Claude Code, GitHub Copilot CLI และ VS Code (อยู่ในสถานะ preview)
- ฟีเจอร์ agent ส่วนใหญ่ยังเป็น preview หรือทยอยเปิด องค์กรยังไม่ควรวางแผนใช้งานจริง (production) ทันที

## 2. US–China AI War
- **Nvidia ประกาศงบไตรมาส 3 ปีงบ 2027** (ประกาศราว 04:20 น. วันที่ 18 พ.ย. เวลาไทย): รายได้ **115.8 พันล้านดอลลาร์** เพิ่มขึ้น **103% YoY** และ **20% QoQ** สูงกว่าที่นักวิเคราะห์คาดไว้ราว 109 พันล้านดอลลาร์
- รายได้ Data Center **107.6 พันล้านดอลลาร์ (+110% YoY)**, Gross margin **74.8%**, EPS (GAAP) **2.70 ดอลลาร์**
- **คาดการณ์ไตรมาส 4 อยู่ที่ 130 พันล้านดอลลาร์ (±3%) โดยไม่นับรายได้ Data Center compute จากจีนเลย** แสดงว่ามาตรการคุมส่งออกชิปทำให้ตลาดจีนหายไปจากประมาณการของ Nvidia
- เริ่มส่งมอบ rack **Vera Rubin NVL72** แล้วในไตรมาสนี้ และจ่ายคืนผู้ถือหุ้น (ซื้อหุ้นคืน + ปันผล) **28.1 พันล้านดอลลาร์**
